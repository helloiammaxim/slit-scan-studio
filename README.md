# Slit-Scan Studio

A browser tool for slit-scan and time-displacement effects. Every pixel of the picture can show a different moment of the video, so motion turns into stretched, bent and folded time.

**Open the tool:** open `index.html` in a browser. No install needed (WebGL 2 required).

- Load a video, or drop one onto the page; drop an image to use it as your own time map
- **Time map** technique: Flat, Linear, Radial, Angular/spiral, Wave, Noise, Mosaic, Luma (time displacement) and Image maps, with depth, offset, repeat, mirror, steps, curve and drift
- **Strip scan** technique: photo-finish style scanning with a vertical or horizontal slit, scroll or wipe
- Effects: Echo (average, lighten, darken), Motion extract and Difference
- 21 built-in presets, plus your own saved, exported and imported presets
- Views for the result, the time map and the source with the slit
- Export PNG, JPG or WebP frames (1× or 2×) and record WebM/MP4 video live or for one pass of the clip

Shortcuts: `Space` play/pause · `[` `]` previous/next preset · `V` switch view · `R` record · `F` freeze the buffer
